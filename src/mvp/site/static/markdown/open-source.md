# Open Source

The Perseus Digital Library has a long history of providing access to its texts, data, and code. This page lists  where you can currently find access to ou TEI-XML corpora, code, and treebank data.
For information on our earlier downloads and corpora please visit our [legacy P4 page](https://www.perseus.tufts.edu/hopper/opensource/download). 


## Research Repositories

Perseus Digital Library text collections and code can be found on [GitHub](https://github.com/PerseusDL)

Long term preservation of the Perseus Digital Library text and images are supported by the Tufts University [Tisch Library](https://tischlibrary.tufts.edu/) and the [Tufts Digital Library](https://dl.tufts.edu/).



## Treebanks and Other Linguistic Annotations

The current home for Perseus treebank data can be found [here](https://github.com/PerseusDL/treebank_data).
