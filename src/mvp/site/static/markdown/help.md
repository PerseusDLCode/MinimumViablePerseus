# Help

<h2 id="experimental-texts">Experimental texts</h2>

Texts marked **Experimental** are provisional editions generated from uncorrected OCR. They haven't been proofread: expect misread characters, missing or garbled words, and imperfect citation structure. When a curated edition of the same work exists, prefer it. You can hide experimental texts on the [Collections](/collections/?status=curated) page with the Status filter.
